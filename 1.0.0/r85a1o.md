# b64decode

- use `validate=True` to detect incorrect base64 

```python
import base64

try:
    decoded_bytes = base64.b64decode(audio_base64, validate=True)
except base64.binascii.Error as e:
    print("Lỗi giải mã Base64:", e)
```

# io.BytesIO

- file-like object
- xử lý dữ liệu nhị phân tạm thời, như dữ liệu từ mạng hoặc dữ liệu được giải nén
