Simple Web Page Example

This is a simple example demonstrating basic HTML and CSS features that our custom browser can render.

The browser supports:

  • HTML parsing with proper DOM tree construction
  • CSS parsing with selector matching and specificity
  • Style computation with inheritance and cascading
  • Layout calculation using the CSS box model
  • Canvas-based rendering with colors, borders, and text
Note: This is a highlighted section with custom styling to demonstrate CSS class selectors and background colors.

You can test different HTML and CSS features by entering them in the address bar above.
