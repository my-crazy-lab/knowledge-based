# Monitoring Tools checklists

- Enable and Configure Slow Query Logging
    - Set slowOpThresholdMs to an appropriate value (e.g., 100ms) to log slow operations.
    - Configure the profiler mode to slowOp or all as needed.
- Utilize Real-Time Monitoring Tools
    - `mongostat`: Provides real-time statistics on database operations.
    - `mongotop`: Displays read and write activity per collection.
- Leverage `db.currentOp()` for Active Operations
