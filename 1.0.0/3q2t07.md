## Giải thích bổ sung về Compilation vs JIT Compilation

- **Compilation (AOT - Ahead-of-Time):**  
  - Toàn bộ source code được chuyển thành máy mã (machine code) trước khi chạy  
  - Máy mã được lưu trữ dưới dạng file thực thi, có thể chạy nhiều lần sau đó  
  - Thời gian biên dịch lâu hơn nhưng chạy nhanh hơn vì không phải compile lúc runtime  

- **JIT Compilation:**  
  - Source code được compile thành máy mã ngay tại thời điểm runtime, trong lúc chương trình đang chạy  
  - Lợi thế là có thể tối ưu code dựa trên dữ liệu thực tế và ngữ cảnh chạy  
  - Nhược điểm là có thêm độ trễ lúc runtime do phải biên dịch ngay khi cần  
  - Thường dùng trong JS engines như V8 để cân bằng giữa tốc độ biên dịch và tối ưu hiệu năng
